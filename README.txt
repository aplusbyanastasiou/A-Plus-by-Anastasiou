HOW LANGUAGES WORK
  - Visitors whose browser is in Greek are sent to the Greek page automatically the
    first time. The EN | ΕΛ switch (header and footer) changes language; the choice
    is remembered.
  - Each page tells Google its language and links to the other version (hreflang),
    with its own description and business details for Larissa.

UPDATING THE LIVE SITE (GitHub Pages)
  The site is published from the GitHub repository "A-Plus-by-Anastasiou".
  To update it: open the repository on github.com > Add file > Upload files, and drag in
  the contents of this folder (index.html, the el folder, favicon.svg, logo.svg),
  replacing the old files (including the two .vcf files). Keep el/index.html inside a folder named "el".
  Changes appear on the live site within a minute or two.
  Note: GitHub Pages addresses are case-sensitive — always write
  A-Plus-by-Anastasiou exactly like this.

CUSTOM DOMAIN (optional, later)
  If you buy a domain (e.g. aplusbyanastasiou.gr), connect it in the repository's
  Settings > Pages > Custom domain, then replace the GitHub address in both
  index.html files and on the business cards.

SAVE CONTACT
  The "Save contact" / «Αποθήκευση επαφής» button downloads a contact card with
  Dimitris's name, phone (+30 698 703 1157), email and Instagram. The phone number is
  not shown anywhere on the page itself. Keep both .vcf files next to index.html.

CONTACT FORM
  There is no server: the form prepares an email to aplusbyanastasiou@gmail.com in the
  visitor's email app (with a Copy button). To receive messages directly, connect a
  form service such as Formspree.

EDITING
  Open the files in a code editor such as VS Code; all text is plain HTML.
  When there is work to show, a "Work" section can be added between the
  ticker and "Services".
