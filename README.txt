HOW LANGUAGES WORK
  - Visitors whose browser is in Greek are sent to the Greek page automatically the
    first time. The EN | ΕΛ switch (header and footer) changes language; the choice
    is remembered.
  - Each page declares its language and links to the other version for Google
    (hreflang), with its own description and business details for Larissa.

PUT IT ONLINE (free options)
  - Netlify Drop: drag this whole 05-Website folder onto app.netlify.com/drop
  - Or GitHub Pages, Cloudflare Pages, or any Greek host (Papaki, Top.Host…):
    upload the folder contents to the site root.
  Then connect the domain aplusbyanastasiou.gr. Using a different domain? Search and
  replace "aplusbyanastasiou.gr" in both index.html files.

CONTACT FORM
  There is no server: the form prepares an email to aplusbyanastasiou@gmail.com in the
  visitor's email app (with a Copy button). To receive messages directly, connect a
  form service such as Formspree or Netlify Forms.

EDITING
  Open the files in a code editor such as VS Code; all text is plain HTML.
  When there is work to show, a "Work" section can be added between the
  ticker and "Services" (ask your designer, or reuse the brand's card style).
